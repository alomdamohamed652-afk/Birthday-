# Birthday Surprise

Interactive birthday website starter.

## Run
Open index.html directly, or:
python -m http.server 5500

## Personalization
Edit config.js.

- recipientName
- birthday (DDMMYYYY)
- lockScreen
- intro
- scratchCards
- letters
- heartMessages
- final

The date gate is a fun frontend gate, not real security; the birthday is visible in client-side JavaScript.
