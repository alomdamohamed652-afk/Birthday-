# 💗 Birthday Surprise\n\nAn interactive, mobile-first birthday website designed as a small personal journey.\n\n## Current experience\n\n1. 🔐 **Birthday PIN gate** — enter the birthday digit by digit.\n2. 🎂 **Birthday hero** — personalized name + soft animated atmosphere.\n3. 💌 **Intro chapter** — a short personal message.\n4. ✨ **Scratch cards** — real mouse/touch scratching with Canvas.\n5. ✉️ **Envelope letters** — click an envelope and read the letter.\n6. ♥️ **Hidden heart hunt** — find every heart to reveal little messages.\n7. 🌸 **Final birthday message** — with replay option.\n8. 📱 **Responsive** — designed for phone first, with desktop support.\n\n## Run locally\n\nOpen index.html directly, or use a local static server:\n\n    python -m http.server 5500\n\nThen open http://localhost:5500.\n\n## Personalization\n\n**You mainly need to edit config.js.**\n\nImportant fields:\n\n- recipientName\n- birthday → exactly 8 digits: DDMMYYYY\n- lockScreen\n- hero\n- intro\n- scratch.cards\n- letters.cards\n- hearts.messages\n- final\n\n### Example\n\n    recipientName: "Jori",\n    birthday: "14022004",\n\nThis means **14 / 02 / 2004**.\n\n## Optional music\n\nIn config.js:\n\n    music: {\n      enabled: true,\n      url: "YOUR_AUDIO_URL"\n    }\n\nThe website will show a small music button after the birthday screen opens.\n\n## Important\n\nThe birthday value is stored in frontend JavaScript. This is a fun surprise gate, **not real security**. Anyone who can inspect the website files can see the configured date.\n\nNo backend or database is required for the current version.
